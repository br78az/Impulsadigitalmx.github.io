 IMPULSA DIGITAL MX

Sitio web oficial de Impulsa Digital MX, empresa enfocada en la gestión de redes sociales para negocios locales en México.

## 📌 Descripción
Este proyecto fue desarrollado como parte de un plan de negocios para la creación de una tienda/servicio online.

La página incluye:
- Información de la empresa
- Servicios y planes
- Estrategia de marketing
- Datos de contacto

## 💻 Tecnologías utilizadas
- HTML5
- CSS3
